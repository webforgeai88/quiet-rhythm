# Проверка проекта

Проверено в Chrome автоматизированными сценариями:

- Все три раздела на ширинах 390, 768, 1024, 1366, 1920 и 2560 px: горизонтального переполнения нет.
- Создание привычки и выбор дней недели.
- Сохранение отметок привычек после перезагрузки.
- Создание задачи, выполнение и фильтр выполненных задач.
- Сохранение идеи после перезагрузки, поиск без учёта регистра, создание задачи из идеи.
- Переключение светлой и тёмной тем.
- Ошибок выполнения JavaScript в проверенных сценариях нет.
- Обработчики голосового ввода проверены на тестовых событиях: повторные результаты не дублируются, промежуточная фраза сохраняется при остановке, отказ в доступе к микрофону отображается.

Реальная диктовка с микрофоном и качество распознавания русского языка не проверены. Для сдачи нужно проверить их в поддерживаемом браузере на опубликованной HTTPS-версии. Публикация на GitHub Pages пока не подтверждена.
После обновления дизайна повторно проверены основные сценарии и все шесть ширин экрана. Добавлены анимация орбиты, переходы разделов и отклик галочек; режим уменьшенного движения предусмотрен.
Проверено обновление «Ягодный сад»: создание задачи со статусом и приоритетом, смена статуса, сохранение после перезагрузки, выполнение и отмена галочкой, перенос старых данных и мобильные фильтры. Все три раздела проверены на шести ширинах: переполнения и ошибок JavaScript нет.

Проверено оформление уютного планера: недельные отметки сохраняются и обновляют дневной список и круговой прогресс. Режим уменьшенного движения отключает анимации листьев. Все разделы на шести ширинах без переполнения.
